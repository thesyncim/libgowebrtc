# Support

## Before Opening An Issue

1. Read the relevant sections of [README.md](README.md).
2. Check [CONTRIBUTING.md](CONTRIBUTING.md) for local verification commands.
3. Confirm whether the problem is a bug, a feature request, or a setup question.

## Where To Ask

- Bug reports: open a bug report issue with a minimal reproduction.
- Feature requests: open a feature request issue with the use case and tradeoffs.
- Security concerns: follow [SECURITY.md](SECURITY.md) and use private reporting.

## What To Include

For runtime and interoperability issues, please include:

- Operating system and architecture
- Go version
- Relevant `LIBWEBRTC_*` environment variables
- Whether the shim was locally built or auto-downloaded
- Logs, stack traces, or a minimal reproduction when possible

Well-scoped reports make it much easier to reproduce and fix problems quickly.
